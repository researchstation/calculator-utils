# Contributing to calculator-utils

Thank you for your interest in contributing to this project!

## Code Review Process

All pull requests require at least one approving review before merging.
Please ensure your code follows the existing style and includes tests
for any new functionality. Reviewers should check for correctness,
readability, and test coverage.

## Before You Start

You will need a GitHub account and Git installed. For larger changes, open an
issue first to discuss the approach and make sure it fits the project.

## Development Workflow

1. Fork this repository on GitHub and clone your fork:

   ```sh
   git clone https://github.com/<your-username>/calculator-utils.git
   cd calculator-utils
   ```

2. Create a branch for your change:

   ```sh
   git switch -c descriptive-change-name
   ```

3. Make your changes and add or update tests when appropriate. Follow the
   existing code style and keep the change focused.
4. Run the tests and other checks relevant to your change. If there is no
   automated check for it, describe how you verified the change.
5. Push your branch to your fork and open a pull request against this
   repository's default branch.

## Opening a Pull Request

In your pull request, explain what changed and why, link any related issue,
and summarize the tests or checks you ran. Be prepared to address reviewer
feedback. All pull requests require at least one approving review before
merging.

## Code Style

- Use meaningful variable names
- Keep functions small and focused
- Add comments only where the intent is non-obvious
